# hash-project
Метод шифрования в программе: Fernet (AES + HMAC)

В нашей программе используется Fernet — криптографический модуль из библиотеки cryptography, который предоставляет простой и безопасный способ симметричного шифрования.

1. Как работает Fernet?
Fernet — это реализация симметричного шифрования, где один и тот же ключ используется для шифрования и дешифрования. Он основан на двух основных криптографических алгоритмах:

- AES-128 (Advanced Encryption Standard) в режиме CBC (Cipher Block Chaining) — для шифрования данных.
- HMAC-SHA256 (Hash-Based Message Authentication Code) — для проверки целостности данных.

Структура зашифрованного сообщения в Fernet: 
Когда Fernet шифрует данные, он создает токен в формате:

Version (1 байт) || Timestamp (8 байт) || IV (16 байт) || Зашифрованный текст (n байт) || HMAC (32 байта)

- Version — версия Fernet (обычно 0x80).

- Timestamp — время создания токена (для защиты от replay-атак).

- IV (Initialization Vector) — случайный вектор инициализации для режима CBC.

- Зашифрованный текст — исходные данные, зашифрованные AES-128-CBC.

- HMAC — подпись для проверки целостности данных.


2. Как работает шифрование в данном коде?

2.1. Генерация ключа

Ключ для Fernet создается на основе мастер-пароля:

def _generate_cipher_key(self):

    key = sha256(self.master_key.encode()).digest() # SHA-256 хеш мастер-пароля

    return base64.urlsafe_b64encode(key) # Кодировка в base64 для Fernet

1. Мастер-пароль хешируется с помощью SHA-256 (получается 32-байтный хеш).

2. Хеш кодируется в base64, чтобы получить ключ, совместимый с Fernet (44 символа).



2.2. Шифрование данных


def encrypt(self, text):
    return self.cipher.encrypt(text.encode()).decode()

1. Текст преобразуется в байты (text.encode()).

2. Fernet шифрует его, добавляя IV и HMAC.

3. Результат преобразуется в строку (decode()).



2.3. Дешифрование данных
def decrypt(self, encrypted_text):
    try:
        return self.cipher.decrypt(encrypted_text.encode()).decode()
    except:
        return None


1. Зашифрованная строка кодируется обратно в байты.

2. Fernet проверяет HMAC и расшифровывает данные.

3. Если ключ неверный или данные повреждены — возвращается None.
